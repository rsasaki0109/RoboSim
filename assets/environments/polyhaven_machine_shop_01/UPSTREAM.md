# Poly Haven industrial environment

This directory contains a small, redistributable industrial render fixture for
the G1 photoreal examples. The binaries are kept at Poly Haven's 1K download
resolution so the examples remain usable on a clean checkout without a
network-dependent asset step.

Poly Haven's assets are CC0. The live API also asks products using the API to
make the Poly Haven source clear, so this provenance record is intentionally
kept next to the files.
