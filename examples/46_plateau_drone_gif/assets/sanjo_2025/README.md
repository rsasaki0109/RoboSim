# PLATEAU Sanjo City 2025 sample

This directory contains the one `56383756` mesh used by Example 46:

- building CityGML with the textured LOD2 Kita-Sanjo Station;
- road CityGML around the station; and
- the station's `Roof.jpg` and `Wall.jpg` Appearance textures.

Source: [3D City Model (Sanjo City) 2025](https://www.geospatial.jp/ckan/dataset/plateau-15204-sanjo-shi-2025)
from Japan's Ministry of Land, Infrastructure, Transport and Tourism (Project
PLATEAU). The complete source archive is published through the official PLATEAU
data catalog.
